# Perfect Dark BRK — attribution and usage notes

The vector lettering in `assets/img/reboot-tomorrow.svg` was drawn from the user-supplied Perfect Dark (BRK) font by Ænigma Fonts / Brian Kent (version 1.40).

1001 Fonts lists Perfect Dark BRK as free for personal and commercial use and links a font-specific license file: https://www.1001fonts.com/perfect-dark-brk-font.html

A published statement attributed to Brian Kent says his fonts are freeware for personal and commercial use, but must not be sold or distributed for profit or altered without permission: https://terms2.line.me/stickerly_opensourcelicense_android/sp?lang=en

This repository does not redistribute the TTF font file. It uses a single vector lettering artwork for the “Reboot tomorrow” display headline. For broader use of the font or distribution of the font file itself, retain the font-specific license and seek clarification from the author at kentpw@norwich.net if necessary.

PROJECT NOTES / CASE STUDY

NotiPlaty

A lightweight Android notification-wrapper concept inspired by dynamic notification islands, with adaptive pill behaviour and optional theme/plugin directions. The project is developed in Flutter/Dart, with a focus on modular architecture and a clean, ad-conscious experience.

Lore Keeper

A Flutter/Dart writing and worldbuilding application with modular theming, structured worldbuilding content and a multi-panel editor. The project explores how an authoring workspace can stay flexible without losing organisation.
